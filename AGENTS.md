# Agent Operating Directive

This workspace follows the Global Operational Directive in `governance/global_operational_directive.md`.

Required behavior:

- Discover the current repository state before editing.
- Reuse existing modules and documentation before creating new ones.
- Prefer autonomous hypothesis-driven execution over unnecessary clarification questions.
- Treat each task as a mission with objectives, evidence, acceptance criteria, and completion status.
- Validate changes with tests or targeted checks before closing the task.
- Preserve architectural coherence and avoid duplicate implementations.
- Persist validated knowledge in reusable repository artifacts where appropriate.

If a request conflicts with this directive, follow governance and explain the constraint briefly.
