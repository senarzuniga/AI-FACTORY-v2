====================================================================
Este catálogo registra el equipamiento productivo común para ambos layouts A y B, con valor estructural para:
- comparación de alternativas
- simulación digital
- análisis de flujo y congestionamiento

4. CAPACITY / FLOW ASSUMPTIONS FOR SIMULATION
====================================================================
Estas cifras son orientativas para modelado y benchmarking; deben validarse con datos reales del cliente o fabricantes. 

Cadena de cálculo obligatoria:
- rated speed -> sustained speed by SKU -> OEE good output -> bundles -> pallets -> transport missions -> plant-constrained output

- Corrugadora Fosber S/LINE: alta capacidad, dependiente de ancho, gramaje, formato y configuración
- Flexo Folder Gluer LMC 42": capacidad media-alta dependiendo del formato y calidad
- Rotary conversion lines: capacidad elevada en tiradas sostenidas
- Young Shin / BOBST plano: sensible a setup y scrap; más variabilidad en tiradas mixtas
- Post 74": la capacidad real se define por flujo de salida y sincronización con expedición
- McKinley y Koppers: no asignar velocidad hasta identificar las máquinas
- ESTAR: incluir la carga manual a 90 grados como restricción de capacidad y ergonomía
- Transfer car: simular handshakes, colas, duty cycle, precisión de parada y fallos de interlock
- EMBA: diferenciar sheets/hour de boxes/hour cuando TwinFeed/DualBox está activo

Indicadores de equilibrio operativo:
- WIP required for continuous feed
- buffer requirement at each machine
- starvation risk if transfer fails
- blocking risk if downstream is saturated
- queue time caused by conveyors / direction changes
- rework probability when second pass is required

====================================================================
5. LAYOUT-SENSITIVE RISK MATRIX
====================================================================
A. Corrugadora / WIP / conversion process
- High risk if WIP orientation change is required
- High risk if conveyors create crossing or merge points
- High risk if a single transfer creates bottleneck

B. Rotary / flat die-cutting / finishing
- High risk if setup is not scheduled and WIP feed is unstable
- High risk if second pass requires material to travel back through path

C. Output / expedition
- High risk if outgoing flow intersects with incoming flow
- High risk if WIP is placed in a way that blocks access to maintenance or forklifts

D. WIP architecture
- A: risk of unnecessary orientation changes and additional transfer time
- B: risk of additional space and extra length in conveyors/transfer, but potentially lower handling intensity if feed is clean
