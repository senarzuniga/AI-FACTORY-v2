03

Perfil técnico del equipo

Configuración de línea 7-color + flexo + die-cutter

  • Tipo VSOP-520, instalación en 2008 según documentación de Drent Goebel.
  • Ancho de web máximo: 20,5 pulgadas.
  • Materiales: papel desde 0,004" y cartón hasta 0,028".
  • Repeat máximo de impresión: 30 pulgadas.
  • 7 unidades offset y 1 unidad flexográfica con cámara de tinta cerrada y bombas de diafragma Tresu.
  • Unwind Martin MBX 10-22-72 con splicer automático.
  • Corona treater previo a la primera unidad; turn bar posterior a la primera unidad para impresión por cara posterior.
  • Secadores: IST UV después de la primera unidad y ESI Down Firing EXCURE 1 EB.
  • Rewinder para impresión de prueba y conexión electrónica con die-cutter Zerand 22" ELS.
  • Sistema de control: BST Register Control System 4400, Quad Closed Loop Color Control, Main Control Console, CIPCON.
  • Control del proceso: Technotrans Apha.D dampening, Floclear filtration, Technotrans Delta.Z temperature control.

Configuración de línea 5-color + flexo + die-cutter

  • Tipo VSOP-520, instalación 2012 según documentación de Mueller Martini.
  • Ancho de web máximo: 20,5 pulgadas.
  • Materiales: cartón desde 0,010" hasta 0,028".
  • Repeat máximo: 30 pulgadas.
  • 5 unidades offset y 1 flexo con cámara de tinta cerrada.
  • Martin unwind, ESI EB dryer, rewinder para prueba y conexión con die-cutter Zerand.
  • Accuweb Wide Away web guide, Polymag CCR web cleaner.
  • Eltromat OFFCON 4 para control de registro y torta de tinta.
  • BST Super Handy Scan 4100, nuevo en 2020; Quad Closed Loop Color Control.
  • 5 sets completos de rodillos nuevos.

03

Technical profile

7-color + flexo + die-cutter configuration

  • Type VSOP-520, installed in 2008 according to Drent Goebel documentation.
  • Maximum web width: 20.5 inches.
  • Materials: paper from 0.004" and paperboard to 0.028".
  • Maximum print repeat: 30 inches.
  • 7 offset print units and 1 flexo unit with enclosed ink chamber and Tresu diaphragm pumps.
  • Martin unwind MBX 10-22-72 with automatic butt splicer.
  • Corona treater before the first unit and turn bar after the first unit for backside printing.
  • Dryers: IST UV after the first unit and ESI Down Firing EXCURE 1 EB.
  • Rewinder for test printing and electronic interface to Zerand 22" ELS platen die-cutter.
  • Control systems include BST Register Control System 4400, Quad Closed Loop Color Control, Main Control Console and CIPCON.

5-color + flexo + die-cutter configuration

  • Type VSOP-520, installed in 2012 according to Mueller Martini documentation.
  • Maximum web width: 20.5 inches.
  • Materials: paperboard from 0.010" to 0.028".
  • Maximum repeat: 30 inches.
  • 5 offset print units and 1 flexo unit with enclosed ink chamber.
  • Martin unwind, ESI EB dryer, test rewinder and interface to Zerand die-cutting.
  • Accuweb Wide Away web guide and Polymag CCR web cleaner.
  • Eltromat OFFCON 4 for register and ink fountain control.
  • BST Super Handy Scan 4100, new in 2020, with Quad Closed Loop Color Control.
  • 5 complete sets of new rollers.
